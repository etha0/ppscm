
1. 상품가격 조정시 엑셀업로드해서 하는 기능
   - 각 상점별로 가격 조정을 할때 엑셀 업로드로 할수 있도록 개선
      > 퍼센터지는 필요없고, 적용가격을 기록한 엑셀을 업로드 할수 있도록 개선

2. 입고내역을 엑셀로 업로드 할수 있도록 기능 개선
3. 발주받은 내역을 pdf 또는 다른 형태의 문서로 다운로드 받을수 있는 기능 (수주내역)
4. 상품이미지를 일괄로 업로드 할수 있는 기능 구현
   > 상품코드_순번.jpg 들을 여러개 한꺼번에 올릴수도 있고, 압축해서 올릴수도 있도록 기능 개선
5. 상점에서 발주를 할때 실제로 insert 하기 전에 재고가 하나라도 부족하면 발주를 못하도록 하고, 재고가 부족해서 발주 실패했다는 에러 메시지 보여줘

## 구현된 메뉴와 양식
- 가격: 매장별 가격 → 엑셀 업로드 → 양식 다운로드. 열은 `매장코드`, `상품코드`, `적용가격`입니다. 퍼센트 대신 고정 가격을 적용합니다.
- 입고: 입고 관리 → 엑셀 업로드. 열은 `상품코드`, `입고수량`, `공급업체`, `입고일`, `메모`입니다. 입고일은 YYYY-MM-DD, 공급업체는 등록된 이름을 사용합니다.
- 수주 PDF: 발주 상세 → 발주서 PDF 다운로드.
- 이미지: 상품 관리 → 이미지 일괄 업로드. JPG 여러 파일 또는 ZIP을 선택합니다. `상품코드_순번.jpg`(순번 1~6)를 받아 대문자 `.JPG`로 저장합니다. 같은 상품·순번만 교체하고 다른 파일은 유지합니다.
- 재고 검사: 모든 발주 상품의 현재 재고를 잠금 조회하고, 한 품목이라도 부족하면 발주 INSERT 전에 중단합니다. 현재 재고와 요청 수량을 오류에 표시합니다. 재고 차감은 기존대로 출고 시 수행합니다(발주 예약 재고 기능은 추가하지 않음).

엑셀은 5MB/1000행, 이미지는 각 5MB/최대 100장/압축 해제 합계 32MB입니다. 이미지 저장 경로는 `SCM_UPLOAD_IMAGES_DIR`입니다.
업로드는 관리자만 가능하며, 오류 시 전체 취소합니다. 가격 변경은 이미 접수된 발주의 확정 단가를 바꾸지 않습니다. 입고 업로드는 재고와 입고 이력을 함께 반영합니다.
